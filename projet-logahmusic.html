LogahMusic - Plateforme musicale

Personnel 2026 PHP / MySQL

Contexte & Besoins

Créer une alternative locale à Spotify/Apple Music pour organiser, importer et écouter ma propre bibliothèque audio. Un projet ambitieux pour maîtriser le développement web full-stack, l'audio en JavaScript et l'interfaçage avec Python.

Langages & Outils

  • PHP 8
  • MySQL
  • JavaScript (Fetch API, Drag & Drop, Web Audio)
  • HTML5 / CSS3 (Flexbox, Grid, Glassmorphism)
  • Python 3
  • FFmpeg (conversion audio)
  • yt-dlp (extraction YouTube)

Travail réalisé

  • Interface Glassmorphism avec sidebar dynamique et lecteur fixe
  • Lecteur audio persistant (sessionStorage + Web Audio API) : la musique ne s'arrête pas entre les pages
  • AJAX complet : favoris, recherche instantanée, ajout aux playlists sans rechargement
  • Drag & Drop pour réorganiser les morceaux des playlists
  • Back-office admin : statistiques, CRUD utilisateurs, gestion des rôles (Admin/User)
  • Import YouTube : PHP appelle Python (yt-dlp + FFmpeg) pour extraire, convertir en MP3 et injecter en BDD
  • Organisation sur mesure : albums avec pochettes personnalisées
  • Sécurité : PDO préparé, htmlspecialchars, sessions

Défis techniques relevés

  • Persistance du lecteur audio : comment ne pas couper la musique lors d'un changement de page en PHP ? Solution : sauvegarde de l'état (temps, source, file d'attente) dans le sessionStorage et rechargement au DOMContentLoaded
  • Communication inter-langages : faire dialoguer PHP et Python pour exécuter des tâches lourdes (téléchargement/conversion) et récupérer le résultat en JSON via shell_exec()
  • Gestion des protections YouTube : contournement des erreurs "403 Forbidden" en implémentant la gestion des cookies (cookies.txt) et l'utilisation de clients alternatifs via yt-dlp
  • Sécurité : protection contre les failles XSS (htmlspecialchars) et les injections SQL (requêtes préparées PDO)

Bilan

Ce projet m'a fait passer au niveau supérieur en full-stack. J'ai résolu des défis techniques complexes : persistance audio entre pages, communication inter-langages, contournement des protections YouTube. C'est mon projet le plus complet à ce jour, mêlant PHP, MySQL, JavaScript avancé et Python.
