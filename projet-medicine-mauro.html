Medicine - Suivi des traitements

Personnel 2026 Java Swing

Contexte & Besoins

Application Java sur mesure pour mon grand-père, qui a besoin d'un suivi quotidien de ses médicaments. L'objectif était de créer une interface simple, lisible et intuitive, avec une horloge en italien et des rappels visuels pour chaque prise.

Langages & Outils

  • Java 8+
  • Java Swing (IHM)
  • Gson (persistance JSON)
  • JTable pour l'affichage des médicaments

Travail réalisé

  • Conception d'une interface en plein écran aux couleurs de l'Italie
  • Horloge en temps réel affichée en italien (Locale.ITALIAN)
  • Cases à cocher pour valider la prise de chaque médicament
  • Persistance des données avec Gson : les cases cochées sont sauvegardées automatiquement
  • Détection du nouveau jour : réinitialisation automatique de toutes les cases chaque matin
  • Gestion spécifique du Calcitriolo (uniquement lundis, mercredis et vendredis)
  • Accessibilité optimisée pour les seniors : police 24px, lignes 50px, cases centrées

Bilan

Ce projet m'a permis de créer une application utile au quotidien pour mon grand-père, tout en approfondissant mes compétences en Java Swing, en persistance de données (JSON) et en conception d'interfaces ergonomiques pour un public spécifique.
